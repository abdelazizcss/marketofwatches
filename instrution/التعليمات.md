Your task is to design and implement a complete professional Admin Dashboard for this project.

Requirements:

- The dashboard must be integrated into the current project, not as a separate project.

- The backend/database will use Supabase (Free Plan).
- Design the dashboard from the beginning with scalability in mind.

• Login page
• Dashboard overview with statistics
• Product management (Create, Read, Update, Delete)
• Category management
• Order management
• Image upload to Supabase Storage
• Search, filtering, pagination and sorting
• Confirmation dialogs
• Toast notifications
• Loading states
• Responsive professional UI

Code requirements:

- Follow the existing project architecture.
- Keep the code modular, reusable and maintainable.
- Use Vanilla JavaScript with ES Modules.
- Use async/await.
- Handle all errors properly.
- Avoid duplicate code.

Most importantly:

Do not generate placeholder code or unfinished components.

Implement every feature completely before moving to the next one.
